# LED Ambilight 2.0 — руководство

Полная версия доступна в приложении: **Руководство** в левом меню.

## Быстрый старт

1. Открой **Подключение**, укажи IP WLED и порт `21324`.
2. Нажми **Подключить WLED (Wi-Fi)**.
3. На **Главной** нажми **Запустить подсветку**.
4. Сверху должно быть **«Захват запущен»** — иначе лента не обновляется.

## Композитор

Композиция — стек слоёв:

- **Экран** — цвет игры/фильма;
- **Звук** — спектр, пульс, VU-метр;
- **Эффект** — огонь, плазма, волна, дыхание, метеор, искры;
- **Уведомление** — короткая вспышка;
- **Spotify** — палитра обложки;
- **Цвет/градиент** — статичная база.

Для каждого слоя доступны прозрачность, порядок, blend-режим и маска.
Звуковой слой лучше ставить в **Сложение**, иначе в тишине он затемняет
Spotify.

Композиция **«Музыка 2.0»** = Spotify + аудио-полосы.

## Автоматизация

Правило: **Когда → Если → Тогда**.

Триггеры:

- процесс/приложение;
- заголовок окна;
- запуск/выход игры;
- время;
- громкость, бас, бит;
- Spotify (смена трека, play/pause);
- Telegram;
- Windows-уведомление;
- потеря WLED.

Действия:

- включить композицию/сцену;
- изменить яркость;
- показать вспышку;
- отправить в Telegram;
- пауза/старт захвата;
- погасить ленту.

**Cooldown** ограничивает частоту, **приоритет** задаёт порядок.

Примеры:

| Когда | Тогда |
|---|---|
| Игра запущена | Композиция «Игра 2.0» |
| Spotify, событие `track` | Композиция «Музыка 2.0» |
| Telegram | Вспышка 2 секунды |
| Время 23:00–07:00 | Сцена «Ночь» |

## Spotify Premium

1. Создай приложение на `developer.spotify.com/dashboard`.
2. Redirect URI: `http://127.0.0.1:8888/callback`.
3. Выбери **Web API** и сохрани.
4. Скопируй Client ID. Client Secret не нужен.
5. В **User Management** добавь свой аккаунт (Development Mode).
6. В LEDAmbilight → **Интеграции** вставь Client ID и нажми
   **Подключить Spotify**, подтверди доступ.

Будут доступны текущий трек, палитра обложки и play/pause/next/previous.
Серая обложка даёт серую палитру.

## Telegram

1. Создай бота у `@BotFather`, скопируй токен.
2. Узнай свой chat_id (например, через `@userinfobot`).
3. В **Интеграциях** введи токен и chat_id, нажми **Запустить бота**,
   затем **Проверить**.

Команды: `/status`, `/off`, `/on`, `/scene Игра`, `/brightness 70`.

Входящие личные сообщения можно подсвечивать через
**Windows-уведомления**. Если `winsdk` недоступен, приложение читает
только число непрочитанных в заголовке Telegram Desktop — без текста
сообщений.

## Звук

- **Системный звук (loopback)** — музыка/игры из колонок.
- **Микрофон / линейный вход** — гитара через аудиокарту.
- **Гибрид** — цвет экрана + оттенок от баса.
- **Визуализатор** — только звук.
- **Спектроанализатор** — частотные полосы по диодам.

## Игры

Полноэкранная игра определяется автоматически. При первом запуске
появляется панель выбора режима; выбор запоминается для exe.
Alt-Tab не сбрасывает сессию; после закрытия процесса возвращаются
прежние сцена, яркость и звук.

## Лента и комната

- **Конфигурация ленты**: метраж, плотность, диагональ, путь.
- **Развёртка**: по одному диоду показывает порядок.
- **Комната**: объёмный предпросмотр.
- **Калибровка**: убирает цветовой сдвиг.
- **Дополнительные ленты**: IP, порт, диоды, смещение, монитор.

## Если что-то не работает

- Нет цвета — проверь «Захват запущен» и активную композицию.
- WLED не подключается — IP, порт `21324`, сеть 2.4 ГГц.
- Spotify 403 — User Management, Redirect URI, Premium.
- Telegram не отвечает — chat_id и запущен ли бот.
- Высокая нагрузка — закрой «Комнату», уменьши FPS, отключи визуализатор.
- Ошибка — **Система → Собрать отчёт**.

## Файлы

- `config.json` — настройки.
- `integrations.json` — токены в Windows DPAPI.
- `%LOCALAPPDATA%\LedAmbilight\app.log` — лог.
