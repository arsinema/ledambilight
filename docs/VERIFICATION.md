# Проверка проекта

Дата последней проверки: 2026-11-19.

## Что запускается

```powershell
python -m compileall -q ledapp tests main.py selftest.py build_exe.py build_installer.py tools
python -m pyflakes ledapp tests main.py selftest.py build_exe.py build_installer.py
python -m ruff check ledapp tests main.py selftest.py build_exe.py build_installer.py --select E9,F63,F7,F82
python -m unittest discover -s tests
python selftest.py
```

## Результат

- Компиляция: без ошибок.
- Pyflakes: без предупреждений.
- Ruff, критичные правила (`E9`, `F63`, `F7`, `F82`): без ошибок.
- Unit-тесты: **52**, все проходят.
- Самотест: **82** проверки, все проходят.
- Импорт всех 30 модулей `ledapp`: без ошибок.
- Сборка onefile: успешно, версия 1.9.0.
- Живой запуск: окно открылось, захват DXGI стартовал, WLED подключён,
  пульт `/api/state` отвечает, аудио включается и выключается.

## Что покрыто тестами

- адаптивный цветовой движок и классический пайплайн;
- маппинг ленты, зоны, HUD-маска, сохранение/загрузка mapping;
- анализ кадра, letterbox и UI-маска;
- пресеты, конфиг, sanitize/deep-merge;
- BLE-команды, MQTT discovery/state;
- remote-сервер: страница, state, brightness, действия;
- погода (классификация), обложка now playing, i18n, redaction;
- игровые режимы: определение, браузеры/плееры, снимок и восстановление,
  кнопки панели;
- сборка: version-файл, `--help` без запуска сборки.

## Что нельзя проверить автоматически на этом ПК

- реальное переключение после закрытия конкретной игры (проверено логикой
  и живым запуском, но не закрытием твоей игры);
- BLE-лента и USB-лента без соответствующего железа;
- реальный MQTT-брокер;
- установщик Inno Setup «глазами» — скрипт собирается, но установка
  проверяется отдельно.

Эти места не выдаются за проверенные: для них нужны реальные устройства
или отдельный тестовый стенд.
