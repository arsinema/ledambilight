# LED Ambilight 2.0.0 — Reactive Room

## Главное

2.0 — это не «ещё две интеграции», а слоистая платформа подсветки.

### Новый интерфейс

- боковая навигация вместо тесной строки вкладок;
- главная страница со статусом, быстрым запуском, сценами, композициями и
  текущим треком Spotify;
- на каждой странице — короткая подсказка «что здесь»;
- встроенное **Руководство**: подключение, композитор, автоматизация,
  Spotify, Telegram, звук, лента;
- четыре темы (ночной синий, океан, слива, лес), пять акцентов и поиск
  по разделам (`Ctrl+K`);
- светлая тема с пастельными акцентными карточками; переключатель темы
  в шапке, «Настройки» — в верхнем меню;
- плавное появление страниц и пульсирующий индикатор захвата;
- живая палитра обложки Spotify на главной;
- иконки Tabler Icons (MIT), карточки и аккуратные скроллбары;
- окно по умолчанию 1180×780.

### Scene Composer

Композиция собирается из слоёв:

- экран;
- звук;
- эффект;
- уведомление;
- Spotify;
- цвет/градиент.

Для каждого слоя — прозрачность, порядок, blend-режим и маска по диодам.
Есть библиотека эффектов: дыхание, волна, плазма, огонь, метеор, радуга,
спектр, VU-метр, пульс, искры и палитра Spotify. Готовые композиции:
«Классический», «Игра 2.0», «Музыка 2.0», «Спокойный вечер».

### Automation Studio

Правила «когда → если → тогда»:

- запуск игры/приложения;
- заголовок окна;
- время;
- громкость/бас/бит;
- Spotify;
- Telegram;
- Windows-уведомления;
- потеря WLED.

Действия: включить композицию/сцену, изменить яркость, показать вспышку,
отправить в Telegram, пауза/старт, blackout. У правил есть приоритет,
cooldown и условия.

### Spotify Premium

- OAuth PKCE, токены в Windows DPAPI;
- текущий трек, обложка и палитра;
- play/pause/next/previous;
- смена композиции по событиям Spotify.

Нужно создать приложение на developer.spotify.com и указать redirect URI
`http://127.0.0.1:8888/callback`, затем вставить Client ID на вкладке
«Интеграции».

### Telegram

- бот-уведомления и команды `/status`, `/off`, `/on`, `/scene`,
  `/brightness`;
- белый список chat_id;
- токен хранится в DPAPI;
- входящие Telegram/другие Windows-уведомления могут подсвечивать ленту
  через опциональный `winsdk`.

## Несколько лент

- дополнительные WLED-устройства: свой IP, порт, число диодов, смещение;
- отдельный захват другого монитора для дополнительной ленты;
- основной профиль 1.x и все настройки сохраняются.

## Производительность

- основные вкладки 2.0 (Композитор/Автоматизация) строятся лениво;
- ассеты комнаты, звук, BLE, Pillow и интеграции не грузятся, пока не нужны;
- на тестовом ПК: около **97–100 МБ** и **<10% CPU** в Task Manager
  (1920×1080, 87 диодов); при открытой комнате/интеграциях цифры выше.

## Ограничения

- Spotify и Telegram требуют своих токенов; без них интеграции выключены.
- Входящие личные сообщения Telegram: через Windows notification listener
  (`winsdk`) или, если его нет, по числу непрочитанных в заголовке
  Telegram Desktop; текст сообщения не читается.
- WGC/HDR — опциональный пакет `windows-capture`; без него работает DXGI.
- Дополнительный монитор использует тот же путь ленты; отдельная раскладка
  для каждого монитора появится в следующем обновлении.
- Тесты: **87** unit + 82 самотеста.
