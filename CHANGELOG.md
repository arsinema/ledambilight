# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.5.0] — 2026-11-09

### Добавлено

- **Автообновление из приложения** для onefile-сборки. Кнопка «Скачать и
  обновить» скачивает `LEDAmbilight.exe` с GitHub, проверяет SHA-256 из API
  релиза, показывает прогресс с отменой и после перезапуска подменяет exe через
  отдельный PowerShell-скрипт. При ошибке копирования старый exe возвращается,
  приложение запускается снова.
- Для onedir/portable и установленной версии остаётся кнопка «Открыть релиз»:
  там нужен установщик или zip целиком.
- Тесты: 81 проверка, включая выбор ассета, проверку домена, откат в скрипте и
  скачивание с локального HTTP-сервера.

## [1.4.1] — 2026-11-09

### Исправлено

- **Падение после выбора области захвата.** Диалог выбора удалялся вместе с
  результатом, и приложение падало сразу после протягивания прямоугольника.
  Теперь результат читается до удаления диалога.

## [1.4.0] — 2026-11-09

### Добавлено

- **Захват окна или области.** В «Система» → «Захват экрана» можно протянуть
  прямоугольник вокруг окна/части экрана. DXGI захватывает только эту область,
  маппинг диодов пересчитывается относительно неё; «Весь экран» возвращает
  обычный режим. Для WGC при выбранной области автоматически используется DXGI.
- **Английский интерфейс.** Переключатель «Язык / Language» в «Системе»:
  русский или английский. Перевод применяется после перезапуска; каталог
  машинный, правки приветствуются.
- **Установщик Windows** (Inno Setup): установка в
  `%LOCALAPPDATA%\Programs\LEDAmbilight` без прав администратора, ярлык в
  «Пуске», удаление, опционально ярлык на рабочем столе и автозапуск.
  Портативный ZIP и одиночный exe остаются.
- Самотест: **76 проверок**, включая валидацию области захвата и языка.

## [1.3.0] — 2026-11-09

### Добавлено

- **Отчёт для поддержки в один клик.** «Система» → «Собрать отчёт»: ZIP
  с логами, конфигом (IP/MAC вырезаны), текущим маппингом и диагностикой.
  Ничего не отправляется автоматически.
- **Пресеты `.ledpreset`.** Экспорт и импорт сцен, калибровки, фильтров,
  ограничения мощности и маппинга. Сетевые адреса и MQTT в пресет не попадают;
  после импорта приложение предлагает перезапуск для обновления интерфейса.
- **MQTT Discovery для Home Assistant.** При включённом MQTT публикуется
  discovery-конфиг light-сущности: вкл/выкл, яркость, доступность и сцена —
  без ручного YAML. Отключается галочкой в настройках MQTT.
- Самотест расширен до 74 проверок: маскирование IP/MAC, валидация пресетов,
  применение настроек и маппинга.

## [1.2.0] — 2026-11-09

### Добавлено

- **Пропуск первых диодов.** В «Параметрах ленты» появилось поле «Пропустить
  первых: N диодов». Эти диоды остаются тёмными, а подсветка начинается с
  N+1-го; маппинг, полноэкранная расстановка, тест-развёртка и раскладка по
  развёртке учитывают смещение. Удобно, если начало ленты спрятано или не
  используется.
- В полноэкранном редакторе и ручном холсте номера точек показываются с учётом
  смещения.

## [1.1.0] — 2026-11-09

### Добавлено

- **Полноэкранная расстановка светодиодов.** В ручном режиме кнопка
  «Расставить на весь экран» открывает монитор целиком, без панели задач:
  клик — диод, ПКМ — меню, `Backspace` — убрать, `Enter` — готово,
  `Esc` — отмена. Точки сразу попадают в существующий ручной маппинг.
- **Фон-снимок экрана по клавише `B`.** Снимок делается без панели задач,
  чтобы внизу не оставалось полосы; по умолчанию — чистая сетка.
- **Английское описание проекта** в GitHub About и краткий English-раздел
  в README — для тех, кто находит репозиторий не из русскоязычной среды.
- Скриншот полноэкранного редактора в `docs/fullscreen-editor.png`.

## [1.0.3] — 2026-11-09

### Исправлено

- **Автопауза гасила подсветку во время фильма или сериала.** Если сцена
  несколько секунд была статичной, а мышь не двигалась дольше настроенного
  простоя, приложение решало, что пользователь ушёл, останавливало захват и
  включало дежурный режим или чёрный цвет. Теперь автопауза по простою не
  срабатывает, пока открыто полноэкранное приложение (`SHQueryUserNotificationState`)
  или активен профиль movie/game. Если пауза уже случилась, а видео включилось,
  подсветка возвращается сама.
- В список видео-процессов добавлены PotPlayer, MPV, MPC-BE, KMPlayer, GOM,
  Windows Media Player, Plex, Kodi, «Кинопоиск», IVI, Wink и Okko — окно плеера
  не на весь экран тоже больше не считается простоем.

## [1.0.2] — 2026-11-06

### Добавлено

- **Проверка обновлений** (вкладка «Система»): приложение спрашивает у GitHub
  номер последнего релиза, показывает доступную версию и открывает страницу
  релиза. Проверку при запуске можно выключить.
- **Портативная сборка**: `python build_exe.py --portable` собирает папку и
  `LEDAmbilight-<версия>-portable.zip` — вариант без установки, который реже
  вызывает ложные срабатывания антивируса.
- Самотест проверяет сравнение версий (`1.0.10 > 1.0.9`, `v1.2.0`).
- BLE-ветка проверена на живом ELK-BLEDOM: подключение, красный/зелёный/синий,
  выключение и отключение.

## [1.0.1] — 2026-11-06

Сервисное обновление: без изменений в логике захвата и отправки цвета.

### Добавлено

- GitHub Actions: самотест и сборка `.exe` на чистой Windows-машине при каждом
  push в `master` и в pull request (`.github/workflows/ci.yml`).
- Метаданные версии в exe: «Свойства → Подробности» показывают `LED Ambilight`
  и версию `1.0.1` вместо пустых полей.
- `Ctrl+Q` — выход из приложения (дополняет кнопку «Выход» и пункт меню трея).
- Самотест проверяет конвертацию кадра BGRA → RGB без OpenCV (4 проверки).
- `CHANGELOG.md` и `RELEASING.md` — порядок выпуска новой версии.

## [1.0.0] — 2026-11-06

Первый публичный релиз с готовым `LEDAmbilight.exe`.

### Добавлено

- Захват экрана через DXGI, WGC как опциональный бэкенд.
- WLED по Wi-Fi (UDP DRGB — цвет каждого диода) и по USB (Adalight).
- ELK-BLEDOM по Bluetooth LE.
- Поэтевиксельная раскладка ленты, шаблоны витков, мастер раскладки по развёртке.
- Калибровка R/G/B, гамма, линейное усреднение, сглаживание вдоль ленты,
  ограничение по току.
- Профили desktop / movie / game, HUD-маска, автообрезка чёрных полос,
  умные зоны, пауза на статике.
- Аудио-реакция (4 режима), сцены, расписание, рассвет-будильник, режим лампы.
- Пульт с телефона, MQTT / Home Assistant, горячие клавиши, работа в трее,
  автозапуск с Windows.
- Кнопка «Выход» в нижней строке окна: завершает приложение, даже если
  включено сворачивание в трей.
- Иконка приложения и версия в окне.

### Исправлено

- Захват в собранном exe: dxcam запрашивал RGB и внутри вызывал `cv2.cvtColor`,
  а OpenCV в exe нет — `ModuleNotFoundError: No module named 'cv2'`, кадры не
  приходили. Теперь кадр берётся в родном BGRA и переводится в RGB средствами
  numpy (`capture.bgra_to_rgb`).
