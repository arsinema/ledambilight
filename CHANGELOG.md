# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] — 2026-11-27

### Интерфейс

- Боковая навигация вместо 15 тесных вкладок; иконки Tabler Icons (MIT).
- Главная: статус, быстрый запуск/пауза, сцены, композиции, устройство,
  профиль и текущий трек Spotify.
- На каждой странице — короткая подсказка «что здесь», плюс встроенное
  «Руководство» с настройкой Spotify, Telegram, автоматизации и звука.
- Обновлённые карточки, скроллбары и тёмная тема; окно 1180×780.

### Scene Composer

- Слоистая композиция: экран, звук, эффект, уведомление, Spotify, цвет,
  градиент.
- Blend-режимы, прозрачность, маски по диапазону/списку диодов, переходы.
- Библиотека эффектов: дыхание, волна, плазма, огонь, метеор, радуга,
  спектр, VU-метр, пульс, искры, палитра Spotify.
- Готовые композиции «Классический», «Игра 2.0», «Музыка 2.0», «Спокойный
  вечер»; редактор с живым превью.

### Automation Studio

- Правила «когда → если → тогда»: процесс, заголовок, игра, время, звук,
  Spotify, Telegram, Windows-уведомления, потеря WLED.
- Действия: композиция, сцена, яркость, вспышка, Telegram, пауза/старт,
  blackout.
- Приоритеты, cooldown, включение/выключение, редактор правил.

### Интеграции

- **Spotify Premium**: OAuth PKCE, текущий трек, обложка/палитра, прогресс,
  play/pause/next/previous; токены в DPAPI.
- **Telegram**: бот-уведомления и команды `/status`, `/off`, `/on`, `/scene`,
  `/brightness`; белый список chat_id; токен в DPAPI.
- **Windows-уведомления**: вспышки на входящие Telegram/Discord/почту через
  `winsdk` (опционально).
- Пульт с телефона: выбор композиции.

### Несколько лент

- Дополнительные WLED-устройства и отдельный захват для другого монитора;
  отдельные количество диодов, смещение и порт.
- Сцены/композиции 1.x и настройки сохраняются; миграция конфига автоматическая.

### Прочее

- WGC/HDR-бэкенд остаётся опциональным (`windows-capture`).
- `soundcard`, `bleak`, `Pillow`, `requests`, ассеты комнаты и вкладки
  Композитора/Автоматизации загружаются лениво.
- Тесты: 84 проверки, самотест 82 (будет дополнено при финальной проверке).

## [1.9.0] — 2026-11-19

### Добавлено

- **Автоматические игровые режимы.** Приложение само определяет полноэкранную
  игру по процессу и окну (браузеры, плееры, лаунчеры и служебные окна
  исключены). При первом запуске игры появляется ненавязчивая панель:
  Ambilight, Ambilight + звук, визуализатор, спектроанализатор или игнор.
- **Выбор запоминается автоматически** для каждого exe; в «Профилях» есть
  список игровых режимов и кнопки «Забыть».
- Перед игрой запоминаются сцена, яркость, фильтры и звук; после завершения
  процесса игры всё возвращается как было. Alt-Tab и оверлеи не сбрасывают
  игровой режим.
- Для игровых режимов со звуком используется **системный звук (loopback)**.

### Оптимизация

- **Цвет диодов читается напрямую из BGRA-кадра** — убрано полное
  преобразование full-HD кадра в RGB (было ~11 мс на кадр).
- Ленивая загрузка `dxcam`, `bleak`, `Pillow`, `requests` и ассетов комнаты:
  неиспользуемые модули не занимают память на старте.
- Комната не грузит пять full-HD QPixmap, пока вкладка скрыта; при открытии
  они уменьшаются до 1280 px, таймер анимации выключается вместе с вкладкой.
- Проверка обновлений идёт через системный `curl`, без `urllib`/`ssl`
  в процессе приложения.
- Ограничен кэш QPixmap и добавлена сборка мусора после старта.
- Замер на этом ПК: **~96 МБ** памяти, **<10% CPU** (Task Manager).
- Тесты: 54 проверки, самотест 82.

### Исправлено

- `soundcard` теперь загружается лениво: порядок импорта модулей больше не
  ломает DXGI-захват через COM.
- `RemoteServer` корректно сохраняет фактический порт при запуске на порту 0.
- `build_exe.py --help` больше не запускает сборку.
- Системные процессы (`dwm.exe` и оболочки Windows) больше не считаются играми.

## [1.8.0] — 2026-11-19

### Изменено

- **Новый адаптивный Color Engine** для поэтевиксельной ленты:
  - гауссово пространственное взвешивание области диода;
  - робастное среднее с обрезкой выбросов;
  - OKLab-кластеризация для резких границ и нескольких значимых оттенков;
  - отдельный путь для мелких ярких объектов;
  - переключение «Адаптивный / Классический» на вкладке «Фильтры».
- Точность на синтетических сценах: средняя ΔE снижена с 0.214 до **0.000**
  на границе красный/синий, с 0.475 до **0.000** на мелком ярком объекте,
  с 0.235 до **0.000** на четырёхцветной зоне.
- Замеры на 87 диодах: извлечение цвета **3.1–3.4 мс** (p50–p95),
  полный кадр **4.0–4.1 мс**; при 60 FPS остаётся запас.
- Классический алгоритм сохранён и переключается без потери настроек.
- Тесты: 22 проверки, самотест 82.

## [1.7.0] — 2026-11-10

### Добавлено

- **Вкладка «Комната»** — объёмный предпросмотр монитора и ленты в комнате.
  Лента светится живыми цветами, комнату можно вращать мышью, колесо —
  приближение. Работает без Qt3D, на обычном QPainter.
- **Умные сцены по заголовку окна**: в «Профилях» теперь можно писать
  `title:YouTube = Кино`; правило срабатывает по части заголовка активного
  окна и имеет приоритет над привязкой по процессу. Есть кнопка
  «Привязать по заголовку».
- **Звук с микрофона/линейного входа**: на вкладке «Звук» можно выбрать
  источник «Микрофон / линейный вход» и конкретную аудиокарту — для гитары,
  подключённой через аудиоинтерфейс. Есть усиление входа.
- Тесты: 18 проверок, включая отрисовку 3D-комнаты, выбор сцены по
  заголовку и усиление аудиовхода.

## [1.6.0] — 2026-11-09

### Добавлено

- **Последняя сцена запоминается.** При выборе «Кино / Игра / Ночь / Яркий
  день» имя сохраняется в `last_scene`. После запуска приложение определяет
  сцену по сохранённым настройкам и показывает её в строке статуса, поэтому
  пресет не нужно выбирать заново. Если после пресета настройки правили
  вручную, они не перезаписываются.
- Тест сцен: 3 проверки, всего 13 unit-тестов; самотест 82.

## [1.5.0] — 2026-11-09

### Добавлено

- **Автообновление из приложения** для onefile-сборки. Кнопка «Скачать и
  обновить» скачивает `LEDAmbilight.exe` с GitHub, проверяет SHA-256 из API
  релиза, показывает прогресс с отменой и после перезапуска подменяет exe через
  отдельный PowerShell-скрипт. При ошибке копирования старый exe возвращается,
  приложение запускается снова.
- Для onedir/portable и установленной версии остаётся кнопка «Открыть релиз»:
  там нужен установщик или zip целиком.
- **Выбор монитора.** «Система» → «Монитор»: второй экран захватывается через
  DXGI `output_idx`, разрешение и координаты маппинга считаются от него. При
  смене монитора старый маппинг сбрасывается, чтобы не брать цвета не из тех
  координат.
- Тесты: 82 проверки, включая выбор ассета, проверку домена, откат в скрипте,
  скачивание с локального HTTP-сервера и `output_idx` для монитора.

## [1.4.1] — 2026-11-09

### Исправлено

- **Падение после выбора области захвата.** Диалог выбора удалялся вместе с
  результатом, и приложение падало сразу после протягивания прямоугольника.
  Теперь результат читается до удаления диалога.

## [1.4.0] — 2026-11-09

### Добавлено

- **Захват окна или области.** В «Система» → «Захват экрана» можно протянуть
  прямоугольник вокруг окна/части экрана. DXGI захватывает только эту область,
  маппинг диодов пересчитывается относительно неё; «Весь экран» возвращает
  обычный режим. Для WGC при выбранной области автоматически используется DXGI.
- **Английский интерфейс.** Переключатель «Язык / Language» в «Системе»:
  русский или английский. Перевод применяется после перезапуска; каталог
  машинный, правки приветствуются.
- **Установщик Windows** (Inno Setup): установка в
  `%LOCALAPPDATA%\Programs\LEDAmbilight` без прав администратора, ярлык в
  «Пуске», удаление, опционально ярлык на рабочем столе и автозапуск.
  Портативный ZIP и одиночный exe остаются.
- Самотест: **76 проверок**, включая валидацию области захвата и языка.

## [1.3.0] — 2026-11-09

### Добавлено

- **Отчёт для поддержки в один клик.** «Система» → «Собрать отчёт»: ZIP
  с логами, конфигом (IP/MAC вырезаны), текущим маппингом и диагностикой.
  Ничего не отправляется автоматически.
- **Пресеты `.ledpreset`.** Экспорт и импорт сцен, калибровки, фильтров,
  ограничения мощности и маппинга. Сетевые адреса и MQTT в пресет не попадают;
  после импорта приложение предлагает перезапуск для обновления интерфейса.
- **MQTT Discovery для Home Assistant.** При включённом MQTT публикуется
  discovery-конфиг light-сущности: вкл/выкл, яркость, доступность и сцена —
  без ручного YAML. Отключается галочкой в настройках MQTT.
- Самотест расширен до 74 проверок: маскирование IP/MAC, валидация пресетов,
  применение настроек и маппинга.

## [1.2.0] — 2026-11-09

### Добавлено

- **Пропуск первых диодов.** В «Параметрах ленты» появилось поле «Пропустить
  первых: N диодов». Эти диоды остаются тёмными, а подсветка начинается с
  N+1-го; маппинг, полноэкранная расстановка, тест-развёртка и раскладка по
  развёртке учитывают смещение. Удобно, если начало ленты спрятано или не
  используется.
- В полноэкранном редакторе и ручном холсте номера точек показываются с учётом
  смещения.

## [1.1.0] — 2026-11-09

### Добавлено

- **Полноэкранная расстановка светодиодов.** В ручном режиме кнопка
  «Расставить на весь экран» открывает монитор целиком, без панели задач:
  клик — диод, ПКМ — меню, `Backspace` — убрать, `Enter` — готово,
  `Esc` — отмена. Точки сразу попадают в существующий ручной маппинг.
- **Фон-снимок экрана по клавише `B`.** Снимок делается без панели задач,
  чтобы внизу не оставалось полосы; по умолчанию — чистая сетка.
- **Английское описание проекта** в GitHub About и краткий English-раздел
  в README — для тех, кто находит репозиторий не из русскоязычной среды.
- Скриншот полноэкранного редактора в `docs/fullscreen-editor.png`.

## [1.0.3] — 2026-11-09

### Исправлено

- **Автопауза гасила подсветку во время фильма или сериала.** Если сцена
  несколько секунд была статичной, а мышь не двигалась дольше настроенного
  простоя, приложение решало, что пользователь ушёл, останавливало захват и
  включало дежурный режим или чёрный цвет. Теперь автопауза по простою не
  срабатывает, пока открыто полноэкранное приложение (`SHQueryUserNotificationState`)
  или активен профиль movie/game. Если пауза уже случилась, а видео включилось,
  подсветка возвращается сама.
- В список видео-процессов добавлены PotPlayer, MPV, MPC-BE, KMPlayer, GOM,
  Windows Media Player, Plex, Kodi, «Кинопоиск», IVI, Wink и Okko — окно плеера
  не на весь экран тоже больше не считается простоем.

## [1.0.2] — 2026-11-06

### Добавлено

- **Проверка обновлений** (вкладка «Система»): приложение спрашивает у GitHub
  номер последнего релиза, показывает доступную версию и открывает страницу
  релиза. Проверку при запуске можно выключить.
- **Портативная сборка**: `python build_exe.py --portable` собирает папку и
  `LEDAmbilight-<версия>-portable.zip` — вариант без установки, который реже
  вызывает ложные срабатывания антивируса.
- Самотест проверяет сравнение версий (`1.0.10 > 1.0.9`, `v1.2.0`).
- BLE-ветка проверена на живом ELK-BLEDOM: подключение, красный/зелёный/синий,
  выключение и отключение.

## [1.0.1] — 2026-11-06

Сервисное обновление: без изменений в логике захвата и отправки цвета.

### Добавлено

- GitHub Actions: самотест и сборка `.exe` на чистой Windows-машине при каждом
  push в `master` и в pull request (`.github/workflows/ci.yml`).
- Метаданные версии в exe: «Свойства → Подробности» показывают `LED Ambilight`
  и версию `1.0.1` вместо пустых полей.
- `Ctrl+Q` — выход из приложения (дополняет кнопку «Выход» и пункт меню трея).
- Самотест проверяет конвертацию кадра BGRA → RGB без OpenCV (4 проверки).
- `CHANGELOG.md` и `RELEASING.md` — порядок выпуска новой версии.

## [1.0.0] — 2026-11-06

Первый публичный релиз с готовым `LEDAmbilight.exe`.

### Добавлено

- Захват экрана через DXGI, WGC как опциональный бэкенд.
- WLED по Wi-Fi (UDP DRGB — цвет каждого диода) и по USB (Adalight).
- ELK-BLEDOM по Bluetooth LE.
- Поэтевиксельная раскладка ленты, шаблоны витков, мастер раскладки по развёртке.
- Калибровка R/G/B, гамма, линейное усреднение, сглаживание вдоль ленты,
  ограничение по току.
- Профили desktop / movie / game, HUD-маска, автообрезка чёрных полос,
  умные зоны, пауза на статике.
- Аудио-реакция (4 режима), сцены, расписание, рассвет-будильник, режим лампы.
- Пульт с телефона, MQTT / Home Assistant, горячие клавиши, работа в трее,
  автозапуск с Windows.
- Кнопка «Выход» в нижней строке окна: завершает приложение, даже если
  включено сворачивание в трей.
- Иконка приложения и версия в окне.

### Исправлено

- Захват в собранном exe: dxcam запрашивал RGB и внутри вызывал `cv2.cvtColor`,
  а OpenCV в exe нет — `ModuleNotFoundError: No module named 'cv2'`, кадры не
  приходили. Теперь кадр берётся в родном BGRA и переводится в RGB средствами
  numpy (`capture.bgra_to_rgb`).
